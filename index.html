About

From systems & networks to cloud-native DevSecOps

I moved from systems, network and basic cloud administration into full-time Cloud and DevOps engineering in 2019, and I bridge engineering velocity with governance, security and operational stability.

I design secure, highly automated infrastructure on Microsoft Azure using Terraform, Kubernetes (AKS) and GitHub Actions / Azure DevOps. At Mavenir I built a centralized, versioned Terraform module library that 10+ project teams use to provision standardised infrastructure without duplicating code.

I embed DevSecOps into delivery: TFLint, tfsec and Checkov run as mandatory pipeline gates, so misconfigurations, exposed secrets and policy violations are caught before anything reaches an environment. Azure RBAC and Azure Policy provide the governance guardrails.

I am also exploring Agentic AI / LLM-based automation (MCP, RAG) to prototype natural-language-driven DevSecOps tooling for pipeline and infrastructure tasks.
